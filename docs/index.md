# AIDE

{{aide}}, the Adventure Integrated Development Environment, is a tool for designing, building and testing adventures.

AIDE is one application, delivered in three ways:

- as a **Node.js web app**, installed with npm and run with the `aide` command;
- as a **Docker image** that wraps the same app;
- as a **desktop app** built with Electron, which wraps the same app again.

:::{note}
AIDE is at an early stage. This documentation describes the tooling and distribution; the features themselves are still to come.
:::
