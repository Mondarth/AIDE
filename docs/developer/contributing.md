# Contributing

The rules for contributions (workflow, required checks, commit messages, the emergency hook bypass and the AI-assistance policy) are in [`CONTRIBUTING.md`](https://github.com/Mondarth/AIDE/blob/main/CONTRIBUTING.md) at the root of the repository.

In short:

1. Fork the repository and branch from `dev`.
2. Set up as described in {doc}`setup`.
3. Write a failing test, then the change.
4. Commit with Conventional Commits (a scope is required).
5. Open a pull request against `dev`. The **CI passed** check must be green before it is merged.
