# Localisation

All user-facing text, including the CLI's output, comes from `messages/<locale>.json` via [Paraglide JS](https://inlang.com/m/gerre34r/library-inlang-paraglideJs). English (`en`) is the base and currently the only locale.

```html
<script lang="ts">
  import { m } from '#lib/paraglide/messages.js';
</script>

<h1>{m.app_name()}</h1>
<p>{m.app_version({ version })}</p>
```

The compiled messages in `src/lib/paraglide/` are generated (by `pnpm install`, `pnpm i18n:compile`, and the Vite plugin) and are not committed.

To add a locale, add it to `locales` in `project.inlang/settings.json` and create `messages/<locale>.json` with the same keys. The server picks the locale for each request (`src/hooks.server.ts`) and writes it into the page's `lang` and `dir` attributes.
